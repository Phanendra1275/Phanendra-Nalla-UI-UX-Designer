# Phanendra Nalla — UI/UX Designer

A responsive portfolio for Nalla Phanendra, built with plain HTML, CSS, and JavaScript.

## Run

Open `index.html` directly in a browser, or serve this folder:

```sh
python -m http.server 4173
```

Then visit http://localhost:4173.

## Structure

```text
portfolio/
  index.html   Semantic sections, navigation, resume CTA and footer
  styles.css   Fonts, design tokens, layouts, breakpoints and motion
  script.js    Project/gallery/testimonial data and interactions
  README.md    Setup and fidelity notes
```

No dependencies, package installation, framework, or build step required. Deploy the directory to any static host.

## Deployment

This is a dependency-free static site. Set the deployment root to this folder and use `index.html` as the entry page.
